# Los' Camping Gear

Optimized GitHub Pages deployment package.

## Upload

Replace the existing `index.html` in the `main` branch with this package's `index.html`, then upload the entire `assets/` folder alongside it.

Also upload:
- `robots.txt`
- `sitemap.xml`
- `404.html`

GitHub Pages should continue serving from the repository root.

## SEO setup

The page includes:
- Canonical URL
- Search-friendly title and meta description
- Open Graph and Twitter metadata
- `WebSite` / `WebPage` structured data
- Semantic H1/H2 headings
- Responsive, accessible search and category navigation
- Affiliate disclosure and link-level affiliate labels
- `robots.txt` and XML sitemap
- Custom 404 page

The Amazon product links themselves were preserved. No Amazon product images, reviews, ratings, prices, or other Amazon-supplied product content were added.
